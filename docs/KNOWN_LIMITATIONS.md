# Refugee Registry — Known Limitations (Uganda Demo Build)

1. **Uganda Code Lists vs. Illustrative Lists**: Lists on the `Code Lists` sheet (`LEGAL_STATUS`, `IDENTITY_DOCUMENT_TYPE`, `SPECIFIC_NEED_CATEGORY`, `REFUGEE_RELATIONSHIP_TO_GROUP`, `DELIVERY_MECHANISM`, `WASHINGTON_GROUP_ANSWER`) and inline `Format / allowed values` (`REFUGEE_GENDER`, `REFUGEE_MARITAL_STATUS`, `PRESENCE_STATUS`, `SECURITY_SCREENING`, `UNACCOMPANIED_CHILD`, `INCOME_SOURCE`, `DELIVERY_MODALITY`, `AUTH_RESULT`, `PAYMENT_STATUS`, `REFUGEE_RECORD_STATUS`, `DUPLICATE_CHECK`, `EXIT_REASON`, `PARTNER_CONSENT`, `LANGUAGE`) match `Uganda_Refugee_Data_Attributes.xlsx`. Settlement/site/programme lists (`ENTRY_POINT`, `REGISTRATION_SITE`, `HOST_DISTRICT`, `SETTLEMENT_LOCATION`, `ZONE_CLUSTER`, `VILLAGE_BLOCK`, `ASSISTANCE_CATEGORY`, `PROGRAMME`, `FOOD_DISTRIBUTION_POINT`) are illustrative Uganda-context demo lists (marked "As per government" / "Settlement-specific" in the source sheet).
2. **Biometrics Out of Scope**: Mandatory biometric attributes `C01` (Facial photograph), `C02` (Fingerprints), and `C05` (Last biometric verification date) are out of scope for this demo build (`TODO` in `register_domain/models/refugee.py`).
3. **Conditional / Recommended / Optional Attributes Omitted from Forms**: Only the 55 non-biometric `Mandatory` attributes are surfaced in the UI forms (`g2p_register_sections.sql`). Legacy DB columns and the 5 non-mandatory sub-register tables (`DisplacementHistory`, `Relative`, `Address`, `EducationRecord`, `OccupationSkill`) are preserved in PostgreSQL (never dropped) and hidden in the UI (`is_active = FALSE`).
4. **Geography Pack**: Master Data geography levels still use the `ETH` country pack (`country > region > zone > woreda`) for platform geo-hierarchy compatibility, while Uganda settlement/district/zone/village attributes (`G01`–`G04`) are captured via dedicated Uganda codelists.
5. **Fictional Demo Data**: All 8 households (`HH-DEMO-0001..0008`) and 25 refugees (`RF-DEMO-0001..0025`) are fictional Uganda-context records.
6. **UI Image Reuse**: `refugee-registry-staff-ui` reuses `openg2p-farmer-custom-staff-ui:0.0.0-develop.716` configured via environment variables and `registry_languages.domain_translation`.
